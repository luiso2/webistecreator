The studio

A private studio, just for you

Nailz By Ash is a boutique, appointment-only nail studio tucked inside a private suite on N Ocean Blvd in Pompano Beach. Every set, from a classic acrylic full set to hand-painted nail art, is done one-on-one with Ashley, no rush, no crowded waiting room.
